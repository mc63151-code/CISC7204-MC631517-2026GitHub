# Module 02 - Data Wrangling

## Overview
This module focuses on data wrangling and data preprocessing. The exercises demonstrate how raw datasets can be cleaned and transformed before further analysis and model development.

## Completed Labs
### Lab 01 - Used Cars Pricing
This lab covers:
* Identifying and handling missing values
* Replacing missing values with appropriate values
* Correcting data formats and data types
* Data standardization and normalization
* Data binning
* Creating indicator variables
* Preparing and exporting a cleaned dataset

### Lab 02 - Laptop Pricing
This lab covers:
* Identifying missing data
* Replacing missing numerical and categorical values
* Correcting data types
* Standardizing and normalizing numerical variables
* Binning laptop prices into categories
* Creating indicator variables for categorical data

The Module 02 folder contains the completed Jupyter Notebook files and relevant datasets used for data wrangling.
