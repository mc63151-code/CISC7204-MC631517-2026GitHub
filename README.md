# Module 06 - Project Challenge

## Overview
This module applies the data analysis techniques learned throughout Modules 01–05 to two project challenges. The projects cover the complete data analytics workflow, including data importing, data wrangling, exploratory data analysis, model development, model evaluation, and model refinement.

## Practice Project - Data Analytics for Insurance Cost
The Insurance Cost project covers:
* Importing and inspecting the insurance dataset
* Data cleaning and preprocessing
* Handling missing values
* Exploratory data analysis
* Regression and boxplot visualization
* Correlation analysis
* Simple Linear Regression
* Multiple Linear Regression
* Pipeline development
* Ridge Regression
* Polynomial transformation and model refinement
* Model evaluation using R-squared

## Final Project - Data Analytics for House Pricing Cost
The House Pricing project covers:
* Importing and inspecting the housing dataset
* Data cleaning and descriptive statistical analysis
* Exploratory data analysis
* Box plots and regression plots
* Simple Linear Regression
* Multiple Linear Regression
* Pipeline development
* Train/test splitting
* Ridge Regression
* Polynomial feature transformation
* Model evaluation using R-squared
