# Module 05 - Model Evaluation and Refinement

## Overview
This module focuses on evaluating and refining machine learning models. The exercises examine model performance on training and testing data and apply techniques to improve model generalization.

## Completed Labs
### Lab 01 - Used Cars Pricing
This lab covers:
* Training and testing data splitting
* Model evaluation using R-squared
* Cross-validation
* Polynomial regression
* Identifying overfitting and underfitting
* Ridge Regression
* Evaluating different alpha values
* Hyperparameter optimization using GridSearchCV

### Lab 02 - Laptop Pricing
This lab covers:
* Train/test splitting
* Cross-validation
* Model evaluation
* Polynomial regression and overfitting analysis
* Ridge Regression
* Evaluating model performance with different alpha values
* Grid search for model refinement
