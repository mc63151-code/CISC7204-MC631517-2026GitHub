# Module 03 - Exploratory Data Analysis

## Overview
This module focuses on Exploratory Data Analysis (EDA). The exercises investigate relationships between variables and identify factors that may influence vehicle and laptop prices.

## Completed Labs
### Lab 01 - Used Cars Pricing
This lab covers:
* Descriptive statistical analysis
* Correlation analysis
* Regression plots
* Box plots
* GroupBy operations
* Pivot tables
* Pearson correlation and p-values
* Investigating relationships between automobile characteristics and price

### Lab 02 - Laptop Pricing
This lab covers:
* Regression plots for CPU frequency, screen size, and weight
* Correlation analysis
* Descriptive statistics
* GroupBy analysis
* Pivot tables and visualization
* Pearson correlation coefficients and p-values
* Investigating relationships between laptop characteristics and price

The Module 03 folder contains the completed Jupyter Notebook files and relevant datasets used for exploratory data analysis.
