# Module 01 - Importing Data Sets
## Overview
This module focuses on importing and understanding datasets using Python and Pandas. The exercises involve loading datasets, examining the structure of the data, assigning column headers, identifying data types, and obtaining basic statistical information.

## Completed Labs
### Lab 01 - Used Cars Pricing
This lab covers:
* Importing the Used Cars Pricing dataset
* Loading data into a Pandas DataFrame
* Assigning appropriate column headers
* Examining the first and last rows of the dataset
* Identifying data types
* Generating basic statistical summaries

### Lab 02 - Laptop Pricing
This lab covers:
* Importing the Laptop Pricing dataset
* Loading and inspecting the dataset with Pandas
* Reviewing dataset structure and column information
* Examining data types and statistical summaries
