# Module 04 - Model Development

## Overview
This module focuses on developing predictive models using regression techniques. Different models are created and evaluated to understand how selected features can be used to predict prices.

## Completed Labs
### Lab 01 - Used Cars Pricing
This lab covers:
* Simple Linear Regression
* Multiple Linear Regression
* Polynomial Regression
* Model visualization
* Prediction using regression models
* Model evaluation using R-squared and Mean Squared Error
* Building a prediction pipeline

### Lab 02 - Laptop Pricing
This lab covers:
* Simple Linear Regression for laptop prices
* Multiple Linear Regression using multiple laptop features
* Polynomial Regression with different polynomial degrees
* Comparing model performance
* Distribution plots
* R-squared and Mean Squared Error evaluation
* Building a pipeline using StandardScaler, PolynomialFeatures, and LinearRegression
